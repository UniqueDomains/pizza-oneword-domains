## 🧱 Field summary

- `domain` — Fully qualified domain name.
- `status` — Current acquisition state for the domain in the public extract.
- `purchase_price` — Visible purchase price when available.
- `renewal_price` — Visible renewal price when available.
- `attractiveness` — Composite naming score used as a decision-support signal.
- `demand` — Relative buyer-pressure score when available.
- `length` — Character count without the TLD.
- `registrar` — Registrar name when known.
- `created_at` — Creation timestamp when known.
- `expires_at` — Expiry timestamp when known.

## ⚠️ Methodology and caveats

These domains are all one-word names on the .pizza extension. That makes the set highly specific: the strongest picks usually read cleanly, match pizza-related use cases, and stay easy to say, spell, and remember. Sample names like Acup.pizza, girls.pizza, WiFi.pizza, homes.pizza, and jewels.pizza show the range from literal keywords to broader brand-style words. When comparing these domains, focus on whether the word adds clarity or confusion next to .pizza. A good name in this set should feel intentional with the extension, not merely available. Because the median ask is 26.8, pricing may be accessible, but relevance and naming risk still matter more than headline cost.

- Best picks read naturally with the .pizza ending
- Check if the word is easy to say, spell, and recall
- Generic terms can help clarity but may feel less distinct
- Unusual pairings can stand out but raise fit and trust risk
